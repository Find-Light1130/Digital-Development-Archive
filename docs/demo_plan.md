# 演示脚本（Demo Plan）

> 面向演示场景的推荐操作路径，按顺序执行可获得完整的展示效果。
> 前置：按 `AGENTS.md` 启动数据、后端与前端（或用 `start.ps1` / `start.sh`）。

## 0. 启动

```bash
python data/raw_data_gen.py        # 生成/重建模拟数据
uvicorn backend.app:app --reload --port 8000
cd frontend && npm run dev         # Vite 默认 3000 端口
```

## 0.5 登录（各角色共用）

1. 打开首页，演示账号入口：

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 学生 | `stu_demo` | `Student123` |
| 教师 | `teacher_demo` | `Teacher123` |
| 年级组长 | `grade_leader_demo` | `Leader123` |
| 管理员 | `admin` | `admin123` |

2. 点击右上角「登录」输入对应账号，登录后自动进入该角色工作台。
3. 可选演示：注册新账号 → 管理员端「用户管理」审核通过 → 再登录使用；
   点击右上角用户名 →「修改密码」→ 用新密码重新登录。

## 1. 学生端（约 3 分钟）

1. 使用 `stu_demo / Student123` 登录，默认绑定学生证号 1；也可在顶部切换学生证号查询。
   - 综合成长指数、预警提示、成长画像、情绪曲线、个性化建议应完整展示。
2. **成绩趋势**：切换科目，点击折线图上的数据点或附近区域，弹出「考试详细总结」。
   - 期中/期末考试标签标色区分（期中琥珀、期末红），无虚影；对照表固定列横向滚动时无文字重叠。
3. **学期下拉**：按学年分组显示（如「2025-2026 学年」下含“初一上 / 初一下”）。
4. **音体美信素质评估**：切换科目查看各维度雷达图与 ABC 等级表（磁吸滚动对齐整列）。
5. **今日心情**：在「情绪曲线」卡片中选择日期与心情（低落 / 平静 / 开心）后点击「记录」，曲线即时更新。
6. **心情标签**：记录时可附加最多 3 个标签（开心/平静/焦虑/疲惫/生气/悲伤），在曲线旁会显示「连续记录 N 天」徽章。
7. **情绪日历**：在「情绪日历」卡片中，已记录日期按心情着色（热力图），点击任意一天可记录/修改当天心情与标签。
8. 点击**随机演示**，观察不同学生画像与建议的差异。

## 2. 教师端（约 4 分钟）

1. 使用 `teacher_demo / Teacher123` 登录（绑定 `初一1班`）。选择班级（如 `初二3班`），点击**查询**。
   - 班级画像雷达、各科平均掌握率（长科目名自动换行，不含音体美信）、班级均分趋势展示。
2. **各科成绩趋势**：切换科目，悬浮数据点查看该次考试的最高/最低/平均分与得分率；
   标签格式为「学期·考试」（如 `初一上·期中`），同名考试跨学期不混淆。
3. **音体美信素质评估卡片**：切换科目查看班级各维度均分与等级分布（悬浮显示各等级人数）。
4. **关注学生列表**：点击某学生的「查看详情」，进入详情页后点「返回班级面板」，
   应回到原班级且班级下拉选中不变（URL 携带 `?class=`，sessionStorage 兜底）。
5. **行为事件录入**：在「行为事件录入」卡片填写学生证号、类型、日期与时长后录入，同日同类型会覆盖原记录。
6. **成绩对照表**：横向滚动，固定“科目”列无内容透出重叠，滚动自动对齐整列。
7. **阅卷端·答题卡**：在「阅卷端 · 答题卡」卡片选择班级，列表展示本年级已进行的考试（已批阅/待批阅）；点击「批阅」进入答题卡，
   每生一行逐格填分（表头标注该科满分，超出范围会被拦截），显示已完成数；点「批阅并自动录入」整班一次入库。
8. **成绩更正**：对同一考试再次「批阅」即覆盖原分数（同键幂等）；亦可调用删除接口更正误录。
9. **获奖登记**：搜索学生 → 填获奖名称/级别/日期登记；登记后可直接「撤销」删除。
10. **数据分布下钻**：在「班级数据分布」卡片点击任意柱子，弹窗列出该区间学生，点击「详情」直达学生档案；卡片头部可折叠，折叠状态本地记忆。
11. **卡片折叠**：各卡片右上角折叠按钮可收起/展开（状态存 localStorage）。

## 3. 年级组长端（约 1 分钟）

1. 使用 `grade_leader_demo / Leader123` 登录（限 `初一年级`）。
2. 查看本年级各班总览、班级分布、年级对比与学科掌握率；访问初二年级数据应被拒绝（403）。
3. 「用户管理」仅显示本年级教师，可对其审核通过/驳回；跨年级教师审核应被拒绝（403）。
4. **本年级考试**：展示本年级考试规划（待进行/已进行/已批阅），到日的「待进行」考试点「进行考试」→ 教师端即可看到并批阅。

## 4. 管理端（约 2 分钟）

1. 使用 `admin / admin123` 登录。
2. 查看全校 KPI（学生总数、平均成长指数）、年级对比柱状图、各班平均成长指数。
3. **各学科平均掌握率表**：行=科目（仅九大学科）、列=年级，颜色分级（≥80 绿 / ≥70 黄 / 其余红）。
4. **全校数据分布下钻**：在「全校数据分布」卡片选择成长指数/各科平均分并点击柱子，弹窗列出该区间学生（含班级）。
5. **用户管理**：审核待注册账号、创建教师/年级组长账号、为教师设置班级。
6. **考试规划**：下拉某年级 → 下达考试（考试类型/科目/年级/日期，超出学业日历会被拒绝），可删除「待进行」规划、
   或直接「进行」已到日的考试，形成 管理端下达 → 年级组长进行 → 教师批阅自动录入 闭环。

## 5. 安全 / 工程验证（可选）

- 浏览器控制台 Network 查看 API 响应含 `Content-Security-Policy` 等安全头；
  页面源码含 CSP `<meta>`（覆盖 SPA 页面本身）。
- 重复提交同一日期的情绪/活动记录，`emotions` / `activities` 表不会产生重复行。
- 成绩批阅重复提交同键覆盖，`scores` 表不产生重复行；阅卷任一生超分/非本班学生整批拒绝。
- 连续输错密码 5 次触发登录限流（429）；修改密码后旧会话立即失效。
- 构建验证：`cd frontend && npm run build` 无 CJS 弃用警告；chunk 已按
  vue/element-plus/echarts 拆分，echarts 为按需引入。
- 自动化测试：`python test/backend_tests.py`、`node test/frontend_tests.js`。

## 回归要点

- 全部学期与单学期场景下，教师端趋势+对照表、学生端折线图+对照表的考试标签不重复、不缺失。
- 浅色主题下回归：ECharts tooltip、下拉悬停高亮、sticky 列背景三处视觉效果。
