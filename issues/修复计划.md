# 修复计划

## I. 学生端

### 1. 不允许学生缺考
- **文件**: `data/raw_data_gen.py:90-96`
- **原因**: `random.random() < 0.005` 概率生成 `score=None`、`exam_type="缺考"` 的记录
- **方案**: 移除该条件分支，使所有学生每次考试都有有效成绩

### 2. 个性化建议图标更换
- **文件**: `frontend/src/views/StudentDashboard.vue:85-88`
- **原因**: 使用加号 `+` SVG 图标
- **方案**: 替换为聊天气泡/书本/灯泡图标，同时更新 `StudentDetail.vue:75` 同位置
- **SVG 替换方案**: 气泡图标（三个圆点+气泡框）

### 3. 成绩对照表固定列字重叠
- **文件**: `frontend/src/components/ScoreChart.vue:284,287`
- **原因**: `.corner` 和 `.row-label` 的 `background: var(--glass-bg)` 是半透明背景，右侧列滚动到固定列下方时文字透出重叠
- **方案**: 将 sticky 列的 `background` 改为 `var(--table-sticky-bg)`（已在 `App.vue:89` 定义，是不透明深色/浅色背景）

### 4. 折线图虚线右侧虚影
- **文件**: `frontend/src/components/ScoreChart.vue:235`
- **原因**: ECharts `markLine` 的 `label` 位置 `insideEndTop` 渲染时标签可能溢出到虚线右侧产生虚影
- **方案**: 将 `position` 改为 `start` 或 `insideStartTop`，确保标签在虚线左侧；或在切换科目时强制 `chartRef.value.clear()`

### 5. 滚动条背景色
- **文件**: `frontend/src/components/ScoreChart.vue` 和 `frontend/src/views/TeacherDashboard.vue`
- **原因**: 浏览器默认滚动条是白色/浅灰色，与深色/浅色主题不一致
- **方案**: 使用 `::-webkit-scrollbar` 自定义滚动条样式，颜色使用主题 CSS 变量：
  - `scrollbar-width: thin`
  - `scrollbar-color` 使用 `var(--glass-border)` / `var(--text-label)`

### 6. 个性化建议语料库丰富
- **文件**: `backend/ai_modules/analysis.py:160-265`
- **原因**: 每个场景只有 3 条模板，随机抽取容易重复
- **方案**: 每个场景扩展至 6-8 条模板，增加多样性

### 7. 下拉框样式
#### 7a. Idle 底色不匹配
- **文件**: `frontend/src/views/StudentDashboard.vue:49`
- **原因**: 学期 `<el-select>` 缺少 `class="glass-select"`
- **方案**: 添加 `class="glass-select"`

#### 7b. 下拉选项悬停高亮
- **文件**: `frontend/src/App.vue:261`
- **原因**: `.el-select-dropdown__item.hover` 和 `:hover` 设置了背景色
- **方案**: 移除 hover 相关背景色，仅保留 `.selected`（选中状态）的高亮样式

## II. 教师端

### 1. 查看详情返回后未保留班级
- **文件**: `frontend/src/views/TeacherDashboard.vue:216` + `frontend/src/views/StudentDetail.vue:3`
- **原因**: `$router.back()` 返回时 `className` 状态丢失（组件卸载）
- **方案**: 
  1. `TeacherDashboard` 在 `router.push` 时传 query 参数：`router.push({ path: '/teacher/student/' + id, query: { class: className.value } })`
  2. `TeacherDashboard` 的 `onMounted` 检查 `route.query.class` 并自动设置 `className` 后加载数据
  3. `StudentDetail` 返回按钮改为 `router.push('/teacher?class=' + classParam)`

### 2. 学生表格第一行不要高亮
- **文件**: `frontend/src/views/TeacherDashboard.vue` + `frontend/src/App.vue:237`
- **原因**: `.glass-table .el-table__body tr:hover` 对所有行统一生效
- **方案**: 
  - 移除或覆盖默认的 row hover，使用 `el-table` 的 `highlight-current-row` 属性
  - 当前行高亮颜色使用 `rgba(var(--accent-rgb), 0.10)` 与主题一致

### 3. 雷达图点线颜色深，选中后线不消失
- **文件**: `frontend/src/views/TeacherDashboard.vue:235-262`
- **原因**: `lineStyle` 使用 `var(--accent)` 但学生端固定用 `#34d399`；`emphasis.lineStyle` 存在时选中行为异常
- **方案**: 
  - 改用固定 `#34d399` 与学生端一致（`--accent` 在浅色模式下变暗 `#059669`）
  - 移除 `emphasis` 中的 `lineStyle`，或使其与常规样式一致

### 4. 条形图 hover 变色+学科名问题
- **文件**: `frontend/src/views/TeacherDashboard.vue:264-296`
- **原因**: 
  - `emphasis.itemStyle.color` 返回原始色但 ECharts 默认 hover 机制会改变颜色
  - `grid.bottom: 20` 不够，长学科名（如"道德与法治"）被截断
- **方案**:
  - 移除 `emphasis` 块，让 ECharts 使用默认 hover 行为
  - `grid.bottom` 增加到 40-50
  - `axisLabel` 添加 `rotate: 30` 或适当减小字号

### 5. 成绩对照表重叠+滚轮问题
- **文件**: `frontend/src/views/TeacherDashboard.vue:429-447`
- **原因**: 同 I.3/I.5，相同代码结构
- **方案**: 同 I.3（sticky 列背景改为 `var(--table-sticky-bg)`） + 同 I.5（自定义滚动条）

### 6. 学年显示+实时更新
- **文件**: `frontend/src/views/TeacherDashboard.vue:97-101`
- **原因**: 学期下拉直接显示学期名而非学年名；右侧表格已用 computed 响应式更新
- **方案**: （需确认具体需求）若需按学年分组，在 `teacherSemesters` 中映射为 "初一上 2025-2026" 格式

### 7. 平均分出现 0
- **文件**: `backend/routes/teacher_api.py:46,63`
- **原因**: `subj_actual[sc.subject][key].append(sc.score if sc.score is not None else 0)` 中缺考记录（score=None）被赋值为 0，导致 `avg_score` 被拉低甚至为 0
- **方案**: 跳过 `score is None` 的记录（`continue`），不加入 `subj_pcts` 和 `subj_actual`

### 8. 关注学生列表底部白线
- **文件**: `frontend/src/views/TeacherDashboard.vue:39-56` + `frontend/src/App.vue:238-239`
- **原因**: `el-table` 的 `td`/`th` 的 `border-bottom` 与 `.glass-card` 的 `border` 叠加
- **方案**: 在 `.glass-table` 添加 `.el-table__body-wrapper` 移除底部边框，或设置 `el-table__body` 最后一行 `border-bottom: none`
